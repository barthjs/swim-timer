# Contributing

Bug reports, ideas, and pull requests are welcome.

## Reporting a bug

Open an [issue](https://github.com/barthjs/swim-timer/issues) with the version of Swim-Timer,
the way it is installed, and what happened compared to what you expected.

## Changing the code

1. For a larger change, open an issue first, so the approach can be agreed on before the work starts.
2. Set up the project as described in the [development documentation](docs/src/content/docs/development/setup.md).
3. Create a branch from `main` and make the change with tests and, where it changes behavior, documentation.
4. Run the tests of every part you changed, see [Testing](docs/src/content/docs/development/testing.md).
5. Open a pull request against `main`. The tests run for every pull request.

Commit messages follow [Conventional Commits](https://www.conventionalcommits.org).
