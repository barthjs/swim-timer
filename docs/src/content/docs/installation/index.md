Swim-Timer is a single binary without further dependencies. Every release is published on the
[releases page](https://github.com/barthjs/swim-timer/releases/latest) with archives for Linux and Windows,
Debian packages, and checksums to verify the downloads.

| Way                             | Suits                                                           |
| ------------------------------- | --------------------------------------------------------------- |
| [Quick start](./quick-start.md) | A first installation with the installation script.              |
| [Linux](./linux.md)             | Linux with the installation script or from a release archive.   |
| [Windows](./windows.md)         | Windows with the installation script or from a release archive. |
| [Debian package](./debian.md)   | Debian and Ubuntu with a system service.                        |
| [Container](./container.md)     | Docker or another container runtime.                            |

After the installation, the web interface is reachable on port 8080. [Updates](./updates.md) describes how each
installation gets a new release.
